engine

Fire Simulator — simulation engine core (Epics E1, E4).

Models the fire on a grid of cells and advances it in discrete ticks. See the package modules: cell, grid, wind, spread, map_gen, scenario, engine, and for towns: landuse, city_gen, population, response, city, session.

class CellState(enum.IntEnum):

Lifecycle of a single cell (matches the cell state-machine diagram).

The values are the codes stored in Grid.state. As the fire passes, a cell moves along UNBURNED -> IGNITING -> BURNING -> BURNED; Grid.ignite sets a cell straight to BURNING, and suppression turns an unburned, igniting or burning cell into SUPPRESSED.

Attributes:
  • UNBURNED: Not on fire (the initial state); only these cells can be ignited by spread.
  • IGNITING: Caught fire this tick; becomes BURNING at the start of the next tick. It does not spread fire or consume fuel yet.
  • BURNING: On fire: can ignite its neighbours and consumes fuel every tick; becomes BURNED when its fuel runs out.
  • BURNED: Burned out; its fuel is exhausted.
  • SUPPRESSED: Suppression was applied; the cell stops burning and spreading fire can no longer ignite it.
UNBURNED = <CellState.UNBURNED: 0>
IGNITING = <CellState.IGNITING: 1>
BURNING = <CellState.BURNING: 2>
BURNED = <CellState.BURNED: 3>
SUPPRESSED = <CellState.SUPPRESSED: 4>
class FuelType(enum.IntEnum):

Kind of fuel in a cell; the values are the codes stored in Grid.fuel.

The fuel sets how a cell burns through the per-fuel tables in this module: FUEL_FLAMMABILITY (how readily it ignites, 0..1), FUEL_BURN_RATE (fuel consumed per burning tick, where a burnable cell starts with 1.0) and FUEL_INTENSITY (relative heat output, used only by UrbanSpreadModel).

Attributes:
  • NONE: Nothing to burn (e.g. water, roads, paving); such a cell never ignites.
  • GRASS: Grass: the most flammable fuel and the quickest to burn out.
  • SHRUB: Shrubs; between grass and forest in flammability and burn rate.
  • FOREST: Forest; ignites less readily and burns longer than grass or shrubs.
  • STRUCTURE: Wood-frame buildings (houses, small shops).
  • MASONRY: Large concrete or brick buildings (schools, hospital); the hardest fuel to ignite.
  • HAZMAT: Fuel pumps and tanks, lithium battery containers; burns hottest and longest.
NONE = <FuelType.NONE: 0>
GRASS = <FuelType.GRASS: 1>
SHRUB = <FuelType.SHRUB: 2>
FOREST = <FuelType.FOREST: 3>
STRUCTURE = <FuelType.STRUCTURE: 4>
MASONRY = <FuelType.MASONRY: 5>
HAZMAT = <FuelType.HAZMAT: 6>
class Grid:

A width x height grid of cells.

Cell properties are stored as parallel NumPy arrays of shape (height, width) so the per-tick update can be vectorized rather than looping cell by cell. The arrays are indexed [y, x] (row, column).

Attributes:
  • width: Number of columns (cells along x), between 1 and MAX_SIDE (400).
  • height: Number of rows (cells along y), between 1 and MAX_SIDE (400).
  • state: int8 array of CellState codes; every cell starts UNBURNED.
  • fuel: FuelType code per cell (default: GRASS everywhere, int8).
  • moisture: Fuel moisture per cell (default 0.10, float32); the spread models multiply a cell's flammability by 1 - moisture.
  • elevation: Relative terrain height per cell, without a unit (default 0, float32); fire spreads faster uphill.
  • fuel_remaining: Fuel left per cell (float32): 1.0 in every burnable cell and 0 where the fuel is FuelType.NONE. A burning cell uses it up and becomes BURNED when it reaches 0.
Grid( width: int, height: int, *, fuel: numpy.ndarray | None = None, moisture: numpy.ndarray | None = None, elevation: numpy.ndarray | None = None)

Create a grid where every cell is unburned.

Arrays passed in are stored as given (not copied) and should have shape (height, width).

Arguments:

  • height: Number of rows (cells along y), between 1 and MAX_SIDE (400).
  • fuel: FuelType code per cell; None fills the grid with GRASS.
  • moisture: Fuel moisture per cell; None uses 0.10 everywhere.
  • elevation: Relative terrain height per cell; None makes the terrain flat (0).
Raises:

class SpreadModel(typing.Protocol):

Strategy interface for the fire-spread algorithm.

SimulationEngine calls ignition_probability once per tick and sets each UNBURNED cell to IGNITING when a uniform random draw falls below the cell's probability. Any class with a matching method can be used.

SpreadModel(*args, **kwargs)
def ignition_probability(self, grid: Grid, wind: Wind) -> numpy.ndarray:

Per-cell probability of igniting this tick (shape = grid shape).

Arguments:
  • grid: The grid to evaluate (cell states, fuel, moisture and elevation).
  • wind: The current wind.
Returns:

Array of shape (height, width) with each cell's probability (0..1) of catching fire this tick. The engine uses it only for UNBURNED cells.

class PhysicsSpreadModel:

Default spread strategy.

Concrete Strategy for SpreadModel: every burning cell may ignite each of its 8 neighbours, with a probability driven by the neighbour's fuel and moisture, the wind and the slope. The engine uses it unless another model is given (wildland scenarios).

def ignition_probability(self, grid: Grid, wind: Wind) -> numpy.ndarray:

Compute each cell's chance of being ignited by its burning neighbours this tick.

Each burning neighbour ignites the cell independently with probability p = BASE_P * susceptibility * wind_factor * slope_factor, capped at MAX_P, and the result is 1 - prod(1 - p) over the burning neighbours, where:

  • susceptibility is the cell's FUEL_FLAMMABILITY times 1 - moisture (clipped to 0..1);
  • wind_factor = 1 + WIND_K * wind.speed_norm * alignment (clipped to 0.1..3), with alignment the cosine between the wind direction and the direction from the neighbour to the cell;
  • slope_factor = 1 + SLOPE_K * tanh(rise / 0.2) (clipped to 0.3..2), with rise the cell's elevation minus the neighbour's, so uphill spread is faster.
Arguments:
  • grid: The grid; reads state, fuel, moisture and elevation.
  • wind: The wind; its direction and normalized speed set the wind factor.
Returns:

float32 array of shape (height, width) with values from 0 to 1; cells without a burning neighbour get 0.

class UrbanSpreadModel(engine.PhysicsSpreadModel):

Spread strategy for towns (wildland-urban interface).

Adds two effects on top of the default model:

  • Source intensity — burning buildings and hazardous sites (fuel, lithium batteries) radiate more heat than vegetation, so they ignite neighbours faster.
  • Ember spotting — wind carries embers 2-4 cells downwind, so fire can jump roads and rivers, which is how most homes catch fire in real urban wildfires.

Concrete Strategy for SpreadModel; create_session uses it for city scenarios.

def ignition_probability(self, grid: Grid, wind: Wind) -> numpy.ndarray:

Compute each cell's ignition chance from neighbour spread and ember spotting.

Neighbour spread uses the default model's formula, with each burning neighbour's p multiplied by the FUEL_INTENSITY of its fuel before the MAX_P cap. When wind.speed_norm is at least MIN_SPOT_WIND (4 km/h), burning cells 2-4 cells away whose direction to the cell is within about 45 degrees of the wind (alignment >= SPOT_ALIGN) add an ember chance of SPOT_BASE * speed_norm * alignment * susceptibility * intensity / distance.

Arguments:
  • grid: The grid; reads state, fuel, moisture and elevation.
  • wind: The wind; it sets the wind factor and the direction and strength of ember spotting.
Returns:

float32 array of shape (height, width) with values from 0 to 1 (all zeros when nothing is burning).

class Scenario:

Settings for one simulation run: map, wind, ignition points and city options.

seed drives every random choice (the map, the fire spread and, in cities, building occupancy), so the same scenario always plays out the same way.

Attributes:

def generate( width: int, height: int, seed: int = 0, *, smoothing: int = 6) -> Grid:

Generate a reproducible wildland grid from a seed.

The same arguments always give the same grid. Elevation is random noise smoothed smoothing times and rescaled to 0..1. Each cell's fuel is drawn independently as GRASS, SHRUB or FOREST with probabilities 0.45, 0.33 and 0.22, and its moisture is uniform in 0.10..0.30.

class SimulationEngine:

Seeded, fixed-step fire simulation on a Grid.

Each advance() moves the fire one tick using a SpreadModel strategy (default PhysicsSpreadModel) and a random generator seeded with seed, so runs are reproducible. Registered TickObserver objects are notified before and after every tick and after a reset (Observer). Playback follows the SimState lifecycle.

Attributes:
  • grid: The grid being simulated; advance() updates its state and fuel_remaining.
  • wind: Wind used by the spread model.
  • seed: Seed of the random generator; reset() re-seeds with it.
  • spread_model: The SpreadModel strategy that gives per-cell ignition probabilities.
  • publisher: Optional event publisher, or None. After every tick it receives publish_state_update(tick, counts), plus publish_extinguished(tick) when that tick leaves the engine COMPLETED.
  • tick: Number of ticks advanced since creation or the last reset().
  • speed: Playback speed set by set_speed (0.25..16, default 1.0). The engine only stores it for clients that pace playback; it does not change advance().
  • state: Current SimState (IDLE at creation).
SimulationEngine( grid: Grid, wind: Wind | None = None, *, seed: int = 0, spread_model: SpreadModel | None = None, publisher=None)

Create an engine in the IDLE state at tick 0.

The grid's current cell states and remaining fuel are saved as the initial condition that reset() restores, and per-cell burn rates are looked up from grid.fuel (FUEL_BURN_RATE) once, here.

Arguments:
  • grid: The grid to simulate; the engine modifies it in place.
  • wind: Wind for the spread model; None means calm air (Wind()).
  • seed: Seed for the random generator that decides which cells ignite.
  • spread_model: Spread strategy; None means PhysicsSpreadModel().
  • publisher: Optional object with publish_state_update(tick, counts) and publish_extinguished(tick) methods, such as messaging.EventPublisher; None disables event publishing.

def start(self) -> None:

Start or resume the run.

Moves IDLE or PAUSED to RUNNING; does nothing in other states. It does not advance a tick by itself: call advance() or run().

def pause(self) -> None:

Pause the run.

Moves RUNNING to PAUSED; does nothing in other states.

def set_speed(self, speed: float) -> None:

Set the playback speed.

Arguments:
  • speed: Requested speed; converted to float and clamped to 0.25..16.
def step(self) -> None:

Advance exactly one tick and settle in the Paused state.

Does nothing once the run is COMPLETED. If the fire goes out during this tick, the engine ends COMPLETED instead of PAUSED.

def stop(self) -> None:

End the run now (e.g. the incident commander closes the incident).

Sets the state to COMPLETED from any state; only reset() leaves it. No event is published.

def reset(self) -> None:

Restore the initial condition and return to IDLE at tick 0.

Restores the cell states and remaining fuel saved at construction or by the last ignite(), re-seeds the random generator with seed (so the fire replays the same way), drops queued suppression and then calls each observer's on_reset. Wind and speed are kept.

def apply_suppression(self, cells: list[tuple[int, int]]) -> None:

Queue suppression; applied on the next tick (reacts to other components).

During the next advance(), after the fire has spread and burned, each listed cell inside the grid that is unburned, igniting or burning becomes SUPPRESSED; other cells are ignored.

Arguments:
  • cells: (x, y) cell coordinates; the values are converted to int.
def advance(self) -> None:

Advance the simulation by one tick.

The steps, in order:

  1. Call each observer's before_tick.
  2. Turn IGNITING cells into BURNING.
  3. Ask the spread model for ignition probabilities and set each UNBURNED cell to IGNITING when its random draw falls below its probability.
  4. Burn fuel in BURNING cells at their fuel's burn rate; cells with no fuel left become BURNED.
  5. Apply queued suppression (see apply_suppression).
  6. Increment tick and call each observer's after_tick.
  7. Set the state to COMPLETED if no cell is burning or igniting.
  8. If a publisher is set, publish the tick's cell counts and, when the engine is COMPLETED, the extinguished event.

It does not check state: callers such as run() and step() decide when to tick.

def run(self, max_ticks: int = 10000) -> int:

Run until the fire is out or max_ticks is reached; returns ticks run.

An IDLE engine is started first. Ticks are advanced only while the state is RUNNING, so a PAUSED or COMPLETED engine runs no ticks.

Arguments:
  • max_ticks: Maximum number of ticks to advance in this call.
Returns:

The number of ticks advanced by this call.

def counts(self) -> dict[str, int]:

Count the cells in each state.

Returns:

Same as Grid.counts: each lowercase state name ("unburned", "igniting", "burning", "burned", "suppressed") mapped to its number of cells.

def snapshot(self) -> dict:

A Memento of the current state, for persistence / replay / resync.

Returns:

Dict with "tick" (the current tick) and "state" (the cell-state codes as nested lists: height rows of width ints).

class SimState(enum.StrEnum):

Lifecycle state of a SimulationEngine.

The values are lowercase strings (e.g. "running"), as reported to API clients.

Attributes:
  • IDLE: Just created or reset; waiting to start.
  • RUNNING: Playing; run() advances ticks only in this state.
  • PAUSED: Paused by pause() or after a single step().
  • COMPLETED: The fire is out (no burning or igniting cell after a tick) or the run was ended with stop(); only reset() leaves this state.
IDLE = <SimState.IDLE: 'idle'>
RUNNING = <SimState.RUNNING: 'running'>
PAUSED = <SimState.PAUSED: 'paused'>
COMPLETED = <SimState.COMPLETED: 'completed'>
class TickObserver(typing.Protocol):

Something that reacts to the engine's tick loop (GoF Observer).

before_tick runs at the start of every tick (it may queue suppression), after_tick after the fire has advanced, and on_reset after a reset. The engine never needs to know what the observer is (e.g. the city layer).

def before_tick(self, engine: SimulationEngine) -> None:

React to the start of a tick, before the fire advances.

Arguments:
  • engine: The engine that is advancing.
def after_tick(self, engine: SimulationEngine) -> None:

React after the fire has advanced and engine.tick has been incremented.

It runs before the engine checks whether the fire is out, so engine.state does not yet show that the fire went out during this tick.

Arguments:
  • engine: The engine that has advanced.
def on_reset(self, engine: SimulationEngine) -> None:

React to the engine being reset to its initial condition.

Arguments:
  • engine: The engine that was reset.

class CityModel:

City layer of one town: people, asset status, priorities and fire crews.

Concrete Observer of SimulationEngine: it implements the TickObserver hooks (before_tick, after_tick, on_reset) and attach registers it. Per-asset values are NumPy arrays of length n indexed by asset id. One tick is one simulated minute. People are conserved: occ + evac + cas == occ0 for every asset.

Asset status, by precedence: burning if any of its cells is burning or igniting; destroyed if at least half of its burnable cells have burned out, damaged if some have; blocked if it has nothing to burn (roads) and fire is within 1 cell; threatened if fire is within THREAT_R; otherwise safe.

Priority score: threat * (lives + hazard) * wind_factor, 0 for a destroyed asset. threat is 1 for a burning or blocked asset and otherwise falls linearly with the fire distance, to 0 beyond ALERT_R; lives is the people at risk times the kind's vulnerability, those needing rescue counted three times; hazard is the kind's hazard until the site explodes; wind_factor (1 to 1.6) raises assets downwind of the fire's centre. Level critical: people at risk in a burning asset, an unexploded hazardous site within 3 cells of fire, or a score of at least 250; high: 80 or more; medium: 20 or more; else low. priorities lists up to 15 assets with a positive score, ordered by level, then by score.

Attributes:
  • ALERT_R: Evacuation is ordered, and people count as at risk, when fire is this close (cells).
  • THREAT_R: An asset is threatened when fire is this close (cells).
  • D_MAX: Largest fire distance tracked (cells); anything farther reads D_MAX + 1.
  • EXPLOSION_R: Unburned fuel within this many cells of an exploding fuel station's site is set alight.
  • CREW_EVAC_BOOST: Extra evacuation rate while a crew works at the asset.
  • RESCUE_RATE: Share of the people needing help that a working crew gets out per tick.
  • MAX_EVENTS: Most entries kept in events; older ones are dropped.
  • map: The town this model runs on.
  • assets: The town's assets, indexed by asset id.
  • asset_id: (H, W) asset id of every cell, -1 where there is none.
  • hour: Hour of day (0-23) at which the incident starts.
  • n: Number of assets.
  • kind: Kind index of every asset (population.KIND_INDEX).
  • vuln: Vulnerability of every asset, from its kind profile.
  • evac_rate: Evacuation rate of every asset, from its kind profile.
  • harm_rate: Harm rate of every asset, from its kind profile.
  • hazard: Hazard score of every asset, from its kind profile.
  • trapped_fraction: Share lost if destroyed, for every asset, from its kind profile.
  • capacity: Capacity (people) of every asset.
  • occ0: People on site at the start, drawn at random (seeded) from the capacity and the presence at hour.
  • stay0: Of occ0, the people who cannot leave without help.
  • delay: Reaction delay (ticks) of every asset; doubled for homes when hour is in population.NIGHT_HOURS.
  • burnable: Number of burnable cells of every asset.
  • has_fuel: True where the asset has at least one burnable cell.
  • is_fuel_station: True for fuel stations.
  • is_battery: True for battery-storage sites.
  • is_building: True for building kinds (population.BUILDING_KINDS).
  • centers: (n, 2) array of asset centres (x, y), in cells.
  • response: The fire crews (ResponseManager).
  • engine: The engine being observed; None until attach.
  • occ: People still inside every asset.
  • stay: Of occ, the people who cannot leave without help.
  • evac: People who got out of every asset alive (including the survivors of an asset that is destroyed).
  • cas: Estimated casualties of every asset.
  • alerted: True once evacuation has been ordered for the asset.
  • alert_tick: Tick at which evacuation was ordered; -1 before that.
  • needs_rescue: People at risk who cannot leave without help; 0 where not at risk.
  • status: Status code of every asset (index into STATUS_NAMES).
  • dist: Distance (cells, 8-neighbour steps) from the asset's cells to the nearest burning or igniting cell; D_MAX + 1 if farther.
  • n_burning: Burning or igniting cells of every asset.
  • burn_frac: Share of the asset's burnable cells that are burning or igniting.
  • burned_frac: Share of the asset's burnable cells that have burned out.
  • at_risk: People inside an asset with fire within ALERT_R or on site (unless it is destroyed); 0 elsewhere.
  • exploded: True for fuel stations that have exploded.
  • hazmat_fired: True once a hazardous site has gone off (battery thermal runaway or fuel-station explosion).
  • events: Event log, oldest first (see log for the entry keys).
  • timeline: One row per tick (a refresh replaces its tick's row) with t, burning, burned, at_risk, casualties, evacuated, bld_burning and bld_destroyed.
  • priorities: Up to 15 assets to protect, most urgent first (see dynamic_payload).
  • peak_at_risk: Most people at risk at once so far.
  • peak_burning_buildings: Most buildings burning at once so far.
  • active_cells: Grid cells burning or igniting now.
  • burned_cells: Grid cells burned out.
  • tick: Current engine tick (0 before attach).

def attach(self, engine: SimulationEngine) -> None:

Register as an observer of an engine and compute the initial state.

Statuses, fire distances and priorities are computed for the current grid; no time passes and nobody moves.

Arguments:
  • engine: The engine running the fire on this town's grid.
def before_tick(self, engine: SimulationEngine) -> None:

Let the fire crews act at the start of a tick (Observer hook).

Moves the crews (dispatching automatically if enabled) and queues the cells they treat with engine.apply_suppression; the engine applies them in the same tick.

Arguments:
  • engine: The engine that is about to advance.
def after_tick(self, engine: SimulationEngine) -> None:

Update the town after the fire has advanced one tick (Observer hook).

Recomputes every asset's status and fire distance, then moves people: evacuation after each asset's reaction delay, rescues by working crews, harm in burning assets and on blocked roads, and losses in destroyed assets. Fuel stations explode (setting the fuel around them alight) and battery sites go into thermal runaway the first time their hazardous cells burn. Priorities, the event log and the timeline are updated too.

Arguments:
  • engine: The engine that has just advanced.
def on_reset(self, engine: SimulationEngine) -> None:

Return the town to the start of the incident after an engine reset (Observer hook).

Restores the starting occupants, clears evacuations, casualties, alerts, the event log and the timeline, puts fresh crews at the station, then recomputes the statuses for the reset grid.

Arguments:
  • engine: The engine that has just been reset.
def refresh(self) -> None:

Recompute statuses and priorities without advancing time (e.g. after a new ignition).

def dispatch(self, asset_id: int):

Send the nearest available fire crew to an asset.

Delegates to ResponseManager.dispatch, which also logs the dispatch.

Arguments:
  • asset_id: Id of the asset to protect (index into assets).
Returns:

The dispatched Crew, or None if every crew is busy.

Raises:
  • IndexError: When asset_id is not between 0 and n - 1.
def set_auto_dispatch(self, enabled: bool) -> None:

Turn automatic crew dispatch on or off and log the change.

While it is on, every tick sends free crews to the most urgent priorities that have no crew yet (any level except low).

Arguments:
  • enabled: True to turn automatic dispatch on, False to turn it off.
tick: int

Current engine tick, i.e. simulated minutes since the start (0 before attach).

def clock(self, tick: int | None = None) -> str:

Format the simulated time of day at a tick.

The incident starts at hour:00 and each tick is one minute.

Arguments:
  • tick: Tick to convert; None means the current tick.
Returns:

The time as "HH:MM" on a 24-hour clock, wrapping past midnight.

def log( self, kind: str, message: str, asset_id: int | None, severity: str) -> None:

Append an event to the incident log.

The entry is a dict with tick, clock, type, message, asset_id and severity. Only the newest MAX_EVENTS entries are kept.

Arguments:
  • kind: Event type, stored under type (e.g. "fire", "evacuation", "dispatch").
  • message: Human-readable description.
  • asset_id: Asset the event is about, or None for a town-wide event.
  • severity: "info", "warning" or "critical"; only critical events are kept as key events by incident_summary.
def population(self) -> dict:

Count the town's people at the current tick.

Returns:

A dict of head counts:

  • total: people on site when the incident started.
  • present: people still inside assets.
  • at_risk: people inside assets at risk (see at_risk).
  • needs_rescue: people at risk who cannot leave without a crew.
  • in_danger: people still inside burning assets or on blocked roads.
  • evacuated: people who got out.
  • casualties: estimated casualties.
  • peak_at_risk: most people at risk at once so far.
def buildings(self) -> dict:

Count the town's buildings by status.

Buildings are the kinds in population.BUILDING_KINDS (not parks or roads).

Returns:

A dict with the current counts total, threatened, burning, damaged and destroyed, and peak_burning (most buildings burning at once so far).

def by_kind(self) -> dict:

Summarise statuses and people for each asset kind present in the town.

Returns:

A dict keyed by kind name (e.g. "house"); kinds without assets are left out. Each row has label, total (number of assets), one count per status name (safe, threatened, burning, damaged, destroyed, blocked), people (on site at the start), present, at_risk, evacuated and casualties.

def hazards(self) -> dict:

Count the hazardous-site incidents so far.

Returns:

A dict with explosions (fuel stations that exploded) and battery_fires (battery-storage sites in thermal runaway).

def area_burned_ha(self) -> float:

Return the area burned or burning, in hectares.

Returns:

(burned_cells + active_cells) times the area of one cell (0.01 ha), rounded to 2 decimals.

def static_payload(self) -> dict:

Build the static description of the town, sent once per scenario.

Returns:

A JSON-ready dict:

  • map_type: always "city".
  • width, height: grid size in cells; cell_size_m: CELL_SIZE_M.
  • landuse, fuel: (H, W) nested lists of LandUse and FuelType codes.
  • elevation: (H, W) nested list, rounded to 3 decimals.
  • assets: Asset.to_dict() of every asset plus occupants0 (people on site at the start).
  • station: the crews' base cell, as a dict with x and y.
  • crews: id and name of every crew.
  • hour: start hour.
  • kinds: label, vulnerability and hazard of every kind in PROFILES.
def dynamic_payload(self) -> dict:

Build the live state of the town, sent with every simulation state update.

Returns:

A JSON-ready dict:

  • clock ("HH:MM"), hour (start hour), minutes (current tick).
  • population, buildings, by_kind, hazards, area_burned_ha: results of the methods of the same name.
  • assets: lists indexed by asset id: status (codes into STATUS_NAMES), occupants, evacuated, casualties, at_risk, needs_rescue, burning and burned (shares of the burnable cells, 2 decimals) and dist (cells to the nearest fire).
  • priorities: up to 15 assets to protect, most urgent first, each with id, kind, name, status (name), level, score, at_risk, needs_rescue, distance_m (metres to the fire, None beyond D_MAX), downwind, reasons (list of strings) and crews (names of the crews assigned).
  • crews: Crew.to_dict() of every crew; crews_available: free crews.
  • auto_dispatch: whether automatic dispatch is on.
  • dispatches, cells_suppressed: crew totals since the last reset.
  • events: the 40 newest events, newest first.
  • timeline: the latest timeline row, or None.
def incident_summary(self) -> dict:

Everything the incident history keeps about this run.

Returns:

A dict:

  • population, buildings, by_kind, hazards, area_burned_ha: results of the methods of the same name.
  • dispatches, cells_suppressed: crew totals for the run.
  • top_losses: up to 5 worst-hit assets (with casualties or destroyed), ranked by casualties, then destroyed buildings with schools, hospitals, fuel and battery sites first; each has name, kind, casualties and status.
  • key_events: the first 60 critical events still in the event log, oldest first.
  • timeline: the timeline rows, thinned to at most 240 (first and last kept).

def create_session( sc: Scenario, *, publisher=None) -> Session:

Build the session.

A scenario whose map_type is not "city" gets a plain engine from SimulationEngine.from_scenario. A city scenario gets an engine on a procedural town with UrbanSpreadModel and its ignition points set alight, plus a CityModel attached to the engine as a tick observer. For a city scenario without ignition points, a default upwind ignition is chosen and written back to sc.ignition_points.

An out-of-range map size raises ValueError from the map generator or Grid (for example a city map smaller than 48 x 48 cells).

Arguments:
  • sc: The scenario to build; a city scenario may get a default ignition point.
  • publisher: Optional event publisher passed to the engine (see SimulationEngine.publisher); None disables event publishing.
Returns:

The new Session; its city is None for wildland scenarios.
