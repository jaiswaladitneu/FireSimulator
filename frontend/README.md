# Frontend (Epic E5 — Visualization & Control UI)

Planned: a React + TypeScript control panel wrapping a Babylon.js 3D view of the
terrain and fire, driven by a live WebSocket feed from the backend. See the UI
mock-ups in the Part B report for the target design.

This directory is a placeholder for the Vite + React + Babylon.js app, owned by
Aditi (E5). It will consume the same REST (`/scenarios`, `/simulation/*`) and
WebSocket endpoints the backend exposes.
